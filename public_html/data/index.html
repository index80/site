SOURCES + DATA QUALITY

INDEX:80 keeps acquisition separate from the static website. This page reads one plain public JSON endpoint at data.index80.com/cardano.json, cached for roughly 15 minutes. GitHub is source control only and is not part of live data delivery. A failed source is marked unavailable or stale, and a missing value is never presented as zero.

REGISTRY PROVENANCE

INDEX:80 also publishes immutable snapshots of its public project registry. Each snapshot remains available as plain JSON, while its SHA-256 fingerprint is anchored to Cardano transaction metadata so the published file can be independently checked later.

WHAT THIS IS — AND ISN'T

This is a public ecosystem observatory, not a trading terminal. The public data contains no wallet addresses, balances, holdings, private signals or account data. Market figures are informational snapshots and should be checked against their linked source before being relied on.

THE PUBLISHING PROCESS

/ HOW IT WORKS

Simple by design: one public file, one fingerprint, one manually approved Cardano transaction.

01

LIVE REGISTRY

The current approved INDEX:80 public registry is the source.

→
02

FREEZE SNAPSHOT

A permanent JSON copy is created for that release.

→
03

HASH + APPROVE

SHA-256 is calculated and the transaction is approved locally in Lace.

→
04

CARDANO PROOF

The fingerprint is recorded on Cardano and linked back here.

PLANNED CADENCE: WEEKLYSnapshot preparation can be automated. Cardano signing always requires manual wallet approval.
INDEPENDENT CHECK

VERIFY A SNAPSHOT YOURSELF

Verifying release INDEX80-0005. Four steps, using only your own computer and a public Cardano explorer.

  1. 1

    DOWNLOAD THE SNAPSHOT

    Save the exact INDEX80-0005 snapshot file. Do not open and re-save it: any change to the bytes changes the hash.

    DOWNLOAD INDEX80-0005 SNAPSHOT JSON VIEW SNAPSHOT TABLE
  2. 2

    CALCULATE SHA-256

    Run one of these commands in the folder containing the downloaded JSON file.

    macOS / Linux

    shasum -a 256 index80-0005.json

    Windows PowerShell

    Get-FileHash .\index80-0005.json -Algorithm SHA256
  3. 3

    COMPARE WITH THE INDEX:80 RELEASE HASH

    The hash returned by your computer should exactly match this value.

    9aff0fa659748fde0a4e746e594172765c91e766eea1cdca5cd9b1f98393a93d

    PowerShell prints the hash in capitals; the letters are the same.

  4. 4

    CHECK THE CARDANO PROOF

    The Cardano Mainnet transaction stores the snapshot fingerprint. Open it and inspect metadata label 309 — the CIP-190 SHA2-256 proof: the hash recorded there should be the same value.

    OPEN CARDANO TRANSACTION ↗

If the hash calculated from your downloaded file matches the INDEX:80 release hash and the hash recorded in the Cardano proof, you have independently verified that this is the snapshot INDEX:80 anchored on-chain.

The whole INDEX:80 database is not written on-chain. Cardano carries the compact proof; the readable registry stays on the open web.

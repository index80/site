Cardano + ADA

Cardano is a proof-of-stake blockchain. ADA is its native currency: it pays transaction fees, participates in staking and governance, and is the base asset used across much of the ecosystem.

Wallets + custody

A wallet manages the keys that authorise transactions; your ADA and native assets remain recorded on-chain. The important distinction is who controls the signing keys and how safely recovery credentials are stored.

Staking

Cardano holders can delegate stake to a stake pool while keeping custody of their ADA. Delegation helps determine block-producing stake and can earn protocol rewards; it is not the same as transferring coins to the pool operator.

CExplorer · CardanoScan
ON-CHAIN CONCEPT

Native assets + policy IDs

Tokens and NFTs can exist directly on Cardano's ledger. A policy ID identifies the minting policy; combined with the asset name it lets users distinguish the intended asset from lookalikes with the same ticker or display name.

Building on Cardano

Developers can work at several layers: smart contracts, transaction construction, APIs, indexers and application frameworks. Aiken is a smart-contract language, while tools such as MeshJS and Blockfrost support application development and data access.

DEVELOPER PATH

eUTXO, Hydra + Mithril

Extended UTXO is Cardano's transaction model for programmable state. Hydra explores high-throughput off-chain execution for specific use cases, while Mithril uses stake-based multi-signatures to create compact, verifiable certificates of Cardano state.

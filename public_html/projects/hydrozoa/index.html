Hydrozoa

VIEW ON GITHUB ↗ Documentation →

INFRASTRUCTURE

Open-source Scala implementation of a multi-party state channel for Cardano, supporting deposits and withdrawals while a head remains open. Hydrozoa provides the operational substrate for the protocol described in the Gummiworm specification.

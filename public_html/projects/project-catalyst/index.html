EDITORIAL NOTE

Project Catalyst remains Cardano's community innovation funding programme using Cardano Treasury funds. In 2026 administration transferred from Input Output Group to the Cardano Foundation, while Cardano also uses direct on-chain treasury-withdrawal governance and an Intersect-facilitated budget process.

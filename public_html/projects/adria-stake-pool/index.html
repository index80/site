EDITORIAL NOTE

Adria Stake Pool is an independent single-pool Cardano operator active since 2021. Its current maintained public destination is DappsOnCardano, an active Cardano ecosystem analytics and discovery site whose footer identifies it as powered by ADRIA Pool.

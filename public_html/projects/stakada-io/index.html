EDITORIAL NOTE

Stakada.io is a Cardano stake-pool discovery and web-tooling service. It provides embeddable pool information and delegation tools for stake-pool websites and surfaces views for Mission Driven Pools, xSPO alliance members and pools using Stakada embeds.

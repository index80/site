# Support

INDEX:80 is a small, maintainer-led open-source project. Support is best-effort: there is no service-level agreement and no commercial support offering.

## Where to ask

| I want to… | Use |
|---|---|
| Report a bug in the site, scripts or tests | A GitHub issue (*bug report* template) |
| Suggest an improvement | A GitHub issue (*feature request* template) |
| Correct a project record, or suggest a project | The form at https://index80.com/submit/, an email to hello@index80.com, or a *data correction* issue |
| Report a security problem | **Privately** — see [SECURITY.md](SECURITY.md). Do not open a public issue |
| Ask about licensing, reuse or a takedown request | hello@index80.com — see [docs/ASSET_PROVENANCE.md](docs/ASSET_PROVENANCE.md) |
| Propose a code change | A pull request — see [CONTRIBUTING.md](CONTRIBUTING.md) |
| Anything else | hello@index80.com |

## What to expect

- Maintainers read issues and email on a best-effort basis and will normally reply, but response times are not guaranteed.
- Data corrections are reviewed against primary-source evidence before any project fact or status changes.
- Not every request will be accepted. Changes that conflict with the project's editorial governance, security or scope may be declined, with a reason where possible.

## What support does not cover

- Financial, investment, tax or legal advice, or any recommendation to use a listed project.
- Payment for inclusion, ranking, Featured status, verification or editorial treatment — these cannot be bought.
- Support for third-party projects listed in the index; contact those projects directly.
- The private submission service behind https://index80.com/submit/, which is not part of this repository.

## Before you ask

Please check the [README](README.md), the [ROADMAP](ROADMAP.md) and existing issues first, and include what you expected, what happened, and the page URL or file path involved. Never include credentials, wallet secrets or private data in an issue.

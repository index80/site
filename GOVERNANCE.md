# Governance

INDEX:80 uses a maintainer-led governance model. This file describes governance as it exists in practice; it does not create a committee, token vote or decentralised structure that does not exist.

## Independence and ownership

INDEX:80 is an independent project created and maintained by Adam Winstanley.

## Project Lead

Adam Winstanley is the Project Lead, Maintainer and Final Editor, with final authority over releases, editorial governance, project inclusion and status decisions, maintainer appointments, funding applications and licensing decisions. Contributing code or evidence does not grant editorial, release, administrative or funding authority.

## Editorial governance

INDEX:80 is human-reviewed. Automation, AI tools and external contributors may gather evidence, propose corrections and improve tooling, but final editorial judgement remains human. No AI system or vendor has editorial authority. The published [Editorial & Open Web Charter](https://index80.com/about/charter/) sets out these principles.

Payment, sponsorship, grants or other funding must not buy inclusion, ranking, Featured status, verification outcome, removal of criticism, or preferred editorial treatment.

Corrections and new project submissions can be sent through https://index80.com/submit/ or hello@index80.com.

## This repository

This repository is the public source snapshot of the website. It contains site code, generators, tests, public data and documentation. Editorial records are maintained in a separate governed workspace and published here as `public_html/data/projects.json`, which is a derivative export, not the editorial master.

## Security and sensitive access

Secrets, signing material, private analytics and unpublished editorial notes are never committed here. Security reporting is described in [SECURITY.md](SECURITY.md).

## Governance changes

The Project Lead approves governance changes. This file is updated when practice changes.
